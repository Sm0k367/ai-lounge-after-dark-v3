## 🛠️ Tech Stack

- **Frontend**: Next.js 15 (App Router) + React + TypeScript
- **Styling**: Tailwind CSS + custom neon glows + CSS animations
- **AI Backend**: Groq API (Llama 3.3 70B – "OMNIPOTENT" mode)
- **Audio**: Web Audio API + custom playlist engine
- **State**: Zustand + persistent context memory
- **Deployment**: Vercel (edge-ready)

## 🚀 Quick Start (Local Development)

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/ai-lounge-after-dark-v3.git
cd ai-lounge-after-dark-v3

# 2. Install dependencies
npm install

# 3. Add your Groq key
cp .env.example .env.local
# → Add GROQ_API_KEY=your_key_here

# 4. Run the neon
npm run dev
